# تجارتي | Tijarati

موقع ثابت ثنائي اللغة يضم ست أدوات مجانية لأصحاب المتاجر والمشاريع الصغيرة. يعمل باستخدام HTML وCSS وJavaScript فقط، دون خادم أو قاعدة بيانات.

## الملفات
- `index.html`: الصفحة الرئيسية وأقسام الموقع والأدوات.
- `styles.css`: التصميم والألوان والاستجابة للشاشات.
- `app.js`: منطق البحث واللغة والحسابات والأدوات.
- `translations.js`: نصوص العربية والإنجليزية.
- `assets/favicon.svg`: أيقونة الموقع.
- `privacy.html` و`terms.html`: صفحات قانونية أولية.
- `robots.txt` و`sitemap.xml`: ملفات أساسية لمحركات البحث.

## التشغيل على Windows
1. فك ضغط ملف ZIP إلى مجلد مناسب.
2. افتح Visual Studio Code.
3. اختر **File > Open Folder** وافتح مجلد `tijarati`.
4. افتح `index.html` في المتصفح بالنقر المزدوج من مستكشف الملفات.
5. للتطوير المريح، يمكنك تثبيت إضافة **Live Server** من متجر إضافات VS Code، ثم الضغط بزر الفأرة الأيمن على `index.html` واختيار **Open with Live Server**. الإضافة اختيارية وليست جزءًا من المشروع.

## تعديل اسم الموقع
ابحث عن `تجارتي` و`Tijarati` داخل `index.html` و`translations.js` وعدّل النصوص. حدّث أيضًا عنوان الصفحة ووصفها في `<head>`.

## تعديل الألوان والخطوط
افتح `styles.css` وعدّل المتغيرات الموجودة في `:root` في بداية الملف، مثل:
- `--ink`: لون النص الأساسي.
- `--paper`: خلفية الموقع.
- `--green`: اللون الرئيسي.
- `--radius`: انحناء الحواف.
- `--shadow`: الظلال.

الخط العربي يستخدم خطوط النظام كبدائل؛ يمكن إضافة خط ويب موثوق لاحقًا إذا رغبت، مع مراعاة الترخيص والأداء.

## تعديل الترجمة
افتح `translations.js`. يحتوي الكائنان `ar` و`en` على مفاتيح النصوص. حافظ على اسم المفتاح نفسه في اللغتين حتى لا يظهر اسم المفتاح بدل النص. العناصر في HTML التي تحمل `data-i18n` تتصل بهذه المفاتيح.

## إضافة أداة جديدة
1. أضف بطاقة أداة داخل `#toolGrid` في `index.html` مع `data-tool` و`data-category`.
2. أضف مفاتيح الاسم والوصف والحقول ورسائل النتائج في كائني `ar` و`en` داخل `translations.js`.
3. أضف بيانات الأداة في `toolInfo`، ثم أنشئ فرعًا جديدًا داخل الدالة `openTool()` في `app.js`.
4. أضف زرًا يحمل `data-open-tool="yourToolId"`، ثم أضف مستمع حدث له قرب نهاية `app.js` أو اجعل ربط الأزرار ديناميكيًا إذا غيرت البنية.
5. اختبر الحسابات في العربية والإنجليزية وعلى شاشة صغيرة.

## اختبار يدوي مقترح
- حاسبة الأرباح: شراء 10، بيع 20، شحن 2، تغليف 1، إضافي 1، رسوم 0% => إجمالي التكاليف 14 والربح 6 وهامش الربح 30%.
- الخصم: سعر 100 وخصم 25% => الخصم 25 والسعر النهائي 75. اختبر أيضًا 0% و100%.
- سعر البيع: تكلفة 80 وهامش 20% => سعر البيع 100.
- الطلب: تكلفة قطعة 5، كمية 3، شحن 3، تغليف 1، إضافي 2 => إجمالي الطلب 21 وتكلفة القطعة 7.
- جرّب الحقول الفارغة والسالبة، والبحث، وتغيير اللغة، واتجاه الصفحة، وأزرار النسخ وإعادة التعيين.
- لم يُنفذ اختبار آلي شامل عبر جميع المتصفحات؛ هذه قائمة اختبار يدوي تساعدك على التحقق محليًا.

## النشر المجاني على GitHub Pages
1. أنشئ حسابًا على GitHub إذا لم يكن لديك حساب.
2. أنشئ مستودعًا جديدًا وارفع جميع ملفات المشروع ومجلد `assets`.
3. من إعدادات المستودع افتح **Pages**.
4. اختر النشر من الفرع الرئيسي `main` والمجلد الجذر `/root` ثم احفظ.
5. انتظر اكتمال النشر وافتح الرابط الذي توفره GitHub Pages.
6. عدّل `sitemap.xml` واستبدل `https://example.com/` بعنوان النشر الحقيقي. راجع أيضًا وصف الموقع وعنوانه في `index.html`.
7. عند تحديث الموقع، ارفع التعديلات إلى المستودع وسيعيد GitHub Pages النشر تلقائيًا.

## حدود النسخة الحالية
- أدوات وصف المنتجات والإعلانات تستخدم قوالب محلية، وليست ذكاءً اصطناعيًا حقيقيًا.
- تغيير العملة يغيّر تنسيق الرمز فقط ولا يحوّل المبالغ بين العملات.
- لا يوجد حساب مستخدم أو قاعدة بيانات أو حفظ للطلبات.
- رابط التواصل `hello@tijarati.example` عنوان تجريبي؛ استبدله بعنوان فعلي قبل النشر.
- صفحات الخصوصية والشروط نصوص أولية وليست استشارة قانونية. حدّثها وفق بلدك وطريقة تشغيل الموقع الفعلية.
- النتائج المالية تقديرية وتعتمد على دقة المدخلات.

## الاستعداد لتحقيق الدخل مستقبلًا
- **الإعلانات:** تحتاج إلى قبول الموقع في شبكة إعلانات، والالتزام بسياساتها وإضافة إفصاحات الخصوصية المطلوبة.
- **التسويق بالعمولة:** تحتاج إلى اتفاقيات مع برامج العمولة وإفصاح واضح عن الروابط التابعة.
- **ميزات مدفوعة:** تتطلب خادمًا آمنًا ونظام حسابات ودفعًا موثوقًا والتحقق من الطلبات؛ لا تضع مفاتيح سرية في JavaScript العام.
- **تقارير قابلة للتنزيل:** يمكن إضافة تصدير محلي للملفات دون خادم، لكن الميزات المتقدمة قد تحتاج مكتبات.
- **التحليلات:** أضفها فقط عند الحاجة مع الإفصاحات ومراعاة قوانين الخصوصية ذات الصلة.

## الترخيص
هذه النسخة مقدمة لتكون أساسًا أوليًا يمكنك تعديله وتطويره.
